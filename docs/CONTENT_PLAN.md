#### 📝 06 - 服务与动作机制
**预计字数**：5000-6000
**核心内容**：
- 服务（Service）同步通信原理
- 服务端与客户端代码实现
- 动作（Action）异步长时间任务
- Action 的 Goal/Result/Feedback
- 实战案例：机器人目标导航服务
- 与话题的对比分析

**代码示例**：
- 创建自定义服务（.srv）
- 服务端节点编写
- 客户端节点编写
- Action 服务器/客户端

**关键命令**：
```bash
ros2 interface show <service_type>
ros2 service call <service> <type> <data>
```

---

#### 📝 07 - 参数服务器与动态参数管理
**预计字数**：4000-5000

- 动态参数修改
- 参数回调函数
- 实战案例：配置驱动的节点行为

**代码示例**：
- 声明参数
- 读取参数
- 监听参数变化
- YAML 配置文件编写

**关键命令**：
```bash
ros2 param list <node>
ros2 param get <node> <param>
ros2 param set <node> <param> <value>
ros2 param dump <node>
```
